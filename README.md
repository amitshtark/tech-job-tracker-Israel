# מנוע סריקה וסינון יומי למשרות פיתוח ג'וניור (0–2 שנות ניסיון)

סקריפט Python אוטונומי שנועד לחסוך בטוקנים ובמשאבים על ידי סינון דטרמיניסטי מלא (Regex + State Tracking) לפני שימוש ב-LLM.

## עקרונות הפעולה
1. **סריקה ישירה מעמודי הקריירה:** סריקה ישירה מתוך `master_companies.json` הכולל 263 חברות טכנולוגיה ומעסיקים בישראל.
2. **ללא פסילת `automation`:** משרות פיתוח אוטומציה ותשתיות נשמרות ועוברות סינון.
3. **תמיכה בכל טווחי 0–2 שנות ניסיון:** זיהוי מפורש של 0 שנות ניסיון, שנה אחת, שנתיים, משרות סטודנט, בוגר טרי ו-Junior.
4. **שימור מלא של פסקת ה-Requirements:** שליפת מלוא הטקסט של הדרישות ללא השמטת מילים.
5. **מעקב שינויים ודלתא בלבד:** שמירת משרות היסטוריות ב-`seen_jobs.json` כך שרק משרות חדשות מוצגות ונשמרות.
6. **שימוש אופציונלי וחינמי ב-Gemini API:** שימוש במפתח חינמי מ-Google AI Studio רק עבור מקרי קצה ספורים שבהם דרישות הניסיון מעורפלות.

## הוראות התקנה והרצה מקומית

1. התקנת הספריות הדרושות:
```bash
pip install -r requirements.txt
```

2. (אופציונלי) הגדרת מפתח Gemini חינמי מ-Google AI Studio (עבור אימות מקרי קצה):
```bash
export GEMINI_API_KEY="your-free-gemini-api-key"
```
*הערה:* אם לא מוגדר מפתח, הסקריפט עובד באופן דטרמיניסטי מלא ומסמן משרות מעורפלות לבדיקה ידנית ללא שום עלות.

3. הרצת הסקריפט:
```bash
python job_crawler.py
```

בסיום הריצה:
* קובץ `seen_jobs.json` מתעדכן אוטומטית.
* אם נמצאו משרות חדשות, נוצר קובץ אקסל יומי בשם `new_jobs_YYYYMMDD.xlsx`.
